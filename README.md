# 🚀 SwapPay – Campus Cash ↔ UPI Exchange Platform

SwapPay is a real-time peer-to-peer exchange platform designed for campus environments, enabling users to seamlessly swap cash and UPI with nearby students.

---

## 🌟 Key Features

### 🔁 Smart Swap System
- Create requests (Need Cash / Need UPI)
- Auto-match or manual match via Swap Feed
- Two-step completion verification

### 🧠 Intelligent Matching
- Auto-Match ON/OFF toggle
- Smart feed with closest amount prioritization
- Trust-based ranking system

### ⭐ Trust & Reputation
- Dynamic trust score system
- User rating (1–5 stars)
- Visual trust badges (Gold / Silver / New)

### 💬 Real-Time Chat
- Socket.IO powered messaging
- Delivered & Seen indicators
- Typing indicators

### 🔔 Real-Time Notifications
- Instant in-app alerts
- Notification bell with unread count
- Animation + Sound + Vibration feedback

### ⚙️ Settings System
- Centralized user preferences
- Notification controls (Sound / Vibration / Animation)
- Auto-match toggle

### 📍 Location-Based Feed
- Nearby swaps using geolocation
- Campus-focused matching

### 🛠️ Admin Panel
- User management
- Swap moderation
- PDF report generation

---

## 🏗️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Real-time:** Socket.IO
- **Authentication:** express-session, bcrypt
- **Background Jobs:** node-cron
- **Email Service:** nodemailer

---

## 🔄 Swap Lifecycle

1. Create Swap Request  
2. Discover via Feed / Auto-Match  
3. Accept & Match  
4. Chat & Coordinate  
5. Mark as Completed (Both Users)  
6. Rate Partner
